Твоя цель создать плагин для tmux, который будет включать в себя таймер для чайной церемонии. Пользователь по нажатию хоткея будет вызывать меню, в котором будет выбор чая, после выбора чая будет выбор как его заваривать (можно выбрать ранее созданные промежутки проливов или создать новые). При этом должна быть возможность добавлять новый чай, для него создавать расписание проливов по умолчанию, добавлять новые расписания и редактировать старые. 

Функционал:
 - Хоткей 1: вызов главного меню с выбором чая 
 - Хоткей 2: начала таймера/ потверждение что пролив слит и переход к ожиданию следующего нажатия для следующего пролива 

Оповещение о проливе должно быть заметным, например вызов на весь терминал ASCII надписи TEA TIME 

При этом все должно быть снабжено красивым дизайном
